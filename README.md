# Number Theory in Python

This is a student practice project for learning basic number theory with Python.

The main idea is to study the mathematics first and then write small Python programs
to test the ideas. The project starts with simple topics and gradually moves toward
topics used in cryptography.

## Topics

1. Integers and divisibility
2. GCD and Euclidean algorithm
3. Extended Euclidean algorithm
4. Prime numbers and factorization
5. Modular arithmetic
6. Modular inverse
7. Chinese Remainder Theorem
8. Fast modular exponentiation
9. Fermat's and Euler's theorems
10. RSA mathematics
11. Quadratic residues
12. Primitive roots and discrete logarithms

## Requirements

- Python 3.x
- No external libraries are required for the basic examples.

## How to run

Open the project folder in VS Code and run any file from the terminal, for example:

```bash
python gcd.py
```

## Purpose

This is mainly a learning and practice repository. The code is kept simple so that
the mathematical steps are easy to follow.
